# 📰 Mon-site

**Responsive article website — A simple web project using HTML, CSS, and JavaScript that displays articles from an API. It includes a burger menu, a dynamic search bar, a client-side validated contact form, and a dark mode.**

## Features

- 📱 Fully responsive design
- 🍔 Burger menu for easy navigation on mobile devices
- 🔍 Dynamic search bar to filter articles
- ✉️ Contact form with client-side validation
- 🌙 Toggleable dark mode
- 📰 Fetches and displays articles from a public API

## Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (ES6)**

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/mon-site.git

2. Navigate into the project directory:
   cd mon-site

3. Open index.html in your browser.

⚠️ This project requires internet access to fetch articles from the API.
